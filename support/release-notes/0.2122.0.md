## Enhancements & Fixes

- Created a query to identify CCDs with multiple screenings that may not have been counted due to the `effectiveDateTime`
  ([#3661](https://github.com/tech-by-design/polyglot-prime/issues/3661))

- Created queries to identify incomplete FHIR submissions.
  ([#3691](https://github.com/tech-by-design/polyglot-prime/issues/3691))

- Added MCO monthly volume reporting.

- Implemented caching for FHIR Bundle validators to optimize performance and reduce memory usage.

- Updated XSLT files to correctly map the encounter class when the code is a CPT code for Epic, AthenaHealth, Medent, CureMD, and Generic CCDA files.
  ([#3704](https://github.com/tech-by-design/polyglot-prime/issues/3704))

- Updated the system to support the `NYSAHCHRSN` screening code in alignment with IG 2.0 requirements.
  ([#3704](https://github.com/tech-by-design/polyglot-prime/issues/3704))
