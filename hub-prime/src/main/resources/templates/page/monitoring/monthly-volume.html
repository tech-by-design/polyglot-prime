Monthly ESMF volume by MCO for the selected reporting month, compared with each earlier month.

Total Records
Records in the MCO's file that month. Rejected files are not counted; resubmissions update the same file.
No of Errors
0 once the file is fully processed; otherwise the current error count.
Difference
Later month minus earlier month. Decreases are in parentheses, e.g. (300).
%
Change from the earlier month, as a whole number. Blank when the earlier month had 0 records.
Blank cell
The MCO had no counted file that month.
Corner mark
More than one file qualified that month; the most recent is shown. Hover the cell for details.
