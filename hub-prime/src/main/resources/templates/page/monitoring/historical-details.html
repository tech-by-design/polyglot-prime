This page provides a clear breakdown of file transmission history across MCOs over selected timeframes.

Key Features & Functionality

  • Summary View: Displays top-level metrics per MCO, including total files received, processed, partially processed, and errored.
  • First-Level Drill-Down: Expand any MCO row to view its associated files along with received month, record counts, and overall status etc.
  • More Information Popup: Click the ⓘ icon on any file row to open a popup with additional metadata, such as resubmission count, last updated time, validation date, and data lake transfer time.
  • Second-Level Drill-Down: Expand an individual file row to reveal status logs and timestamp details for that specific file.
  • Error Details Modal: Click the document icon inside the second-level file view to open the Error Details modal for detailed error logs.

The reporting month is dynamically set based on the submission window (20th of previous month to 4th of current month).
